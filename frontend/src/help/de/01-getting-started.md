# Einführung

## Der Ablauf

![Ablauf: Übersicht, dann Hochladen oder Aufnehmen, dann die Detailansicht mit Editor und Analyse](./assets/main-flow.svg)

Sie beginnen in der Übersicht Ihrer Transkriptionen. Von dort laden Sie eine Datei hoch oder nehmen im Browser auf. Die fertige Transkription bearbeiten Sie in der Detailansicht.

## Ihre erste Transkription

1. Klicken Sie in der Übersicht auf **+ Hochladen** und wählen Sie eine Audio- oder Videodatei. Oder klicken Sie auf **+ Aufnehmen**, um im Browser aufzunehmen; nach dem Beenden lädt transkribierBAR die Aufnahme automatisch hoch. **+ Aufnehmen** erscheint nur, wenn Ihr Browser Aufnahmen unterstützt.
2. Wählen Sie die **Sprache für die Transkription**. Voreingestellt ist **Automatisch erkennen**. Unter **Qualität** wählen Sie das Modell; voreingestellt ist {{default_model}}. Bietet Ihre Installation nur ein Modell an, heißt das Feld **Modell** und zeigt es an.
3. **Sprechende erkennen** ist eingeschaltet und trennt die Beiträge verschiedener Personen. Spricht nur eine Person, können Sie es ausschalten.
4. Klicken Sie auf **Transkribieren**. Läuft der Upload noch, heißt die Schaltfläche **Transkribieren wenn bereit**; die Transkription startet dann von selbst, sobald die Datei hochgeladen ist.
5. Warten Sie, bis die Transkription fertig ist. Die Anzeige zeigt **Warteschlange…**, solange sie wartet, und **Wird transkribiert…**, während sie läuft.
6. Sind Sie auf der Seite geblieben, öffnet sich die fertige Transkription in der Detailansicht von selbst. Sonst klicken Sie sie in der Übersicht an.

> **Seite verlassen?** Solange eine Datei hochgeladen wird, bricht das Verlassen der Seite den Upload ab. Sobald die Transkription läuft, können Sie die Seite verlassen; sie läuft auf dem Server weiter.

## Die Detailansicht

Im Player spielen Sie die Aufnahme ab. Darunter wählen Sie einen Reiter:

- **Untertitel:** den Text korrigieren und unter **Namen der Sprechenden** Namen vergeben. Hier starten Sie auch **Mit LLM verfeinern** und **Übersetzen**.
- **Analyse:** eine Zusammenfassung, ein Sitzungsprotokoll oder eine eigene Auswertung erstellen.
- **SRT**, **VTT**, **JSON** und **TXT:** das Ergebnis im jeweiligen Format ansehen und herunterladen.

## Wo Sie was finden

Die Kopfzeile enthält:

- **?** öffnet diese Hilfe beim Abschnitt zur aktuellen Ansicht.
- **Voreinstellungen** verwaltet Ihre gespeicherten Voreinstellungen.
- **Einstellungen** verwaltet Ihre API-Tokens.
- **EN** stellt die Oberfläche auf Englisch um.
- **Abmelden** meldet Sie ab.

Auf schmalen Bildschirmen finden Sie diese Punkte im **Menü** (Symbol mit drei Strichen). Aus jeder anderen Ansicht führt **← Transkriptionen** zurück zur Übersicht.
